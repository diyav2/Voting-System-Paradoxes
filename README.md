# Voting-System-Paradoxes
Collaborative project through Wolfram Emerging Leaders Program

This project simulates how often different voting systems produce paradoxical outcomes when converting individual votes into a cumulative decision. Using the Wolfram Language, we modeled simple plurality, Borda count, two-round runoff, and instant run-off voting systems, and we validated our functions on a fixed voting pool. Next, we tested each system for paradoxes such as Independence of Irrelevant Alternatives (IIA), Arrow’s Impossibility Theorem, and the Spoiler Effect. To better represent realistic electorates, we generated synthetic populations from voter-candidate ideological profiles over multiple binary issues; voter rankings were produced through Euclidean distance analysis, and population polarization was created by skewing selected issue distributions. Results show that paradox frequency depends heavily on the population profile: systems with first-choice votes are more sensitive to the spoiler effect and candidate-field changes in some electorates, while rank-based methods can still exhibit IIA and outcome reversals. Our framework enables controlled, quantitative comparison of the efficacy of voting rules under realistic population preferences.
